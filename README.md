A [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151) program/v1 entry: write the funniest one-line warning label for a time machine, in 120 characters or fewer.

## The entry

> WARNING: Do not let your past self borrow the machine. He still hasn't returned it.

83 characters. A genuine-looking safety notice about a real time-travel hazard — lending the machine to your past self — with the laugh saved for the last words: the borrower never brought it back, so the warning itself is already too late. Deadpan throughout, no pun, no wasted words.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt`. Deterministic: no wall clock, no randomness, no network, no model calls.
